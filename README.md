## 💻 Sobre o projeto

O **Interface.Lab** é um laboratório de estudos dedicado à construção de interfaces web, ao desenvolvimento de layouts responsivos e à aplicação de princípios de UI/UX (User Interface e User Experience).

O projeto reúne diferentes aplicações desenvolvidas para praticar a criação de páginas web modernas, explorando a estruturação semântica com HTML5, a estilização com CSS3 e a interatividade com JavaScript Vanilla.

Cada projeto possui objetivos específicos, permitindo experimentar diferentes abordagens de design, organização de conteúdo, componentes visuais, animações, formulários e integração com APIs.

A proposta é transformar conceitos de design e desenvolvimento Front-End em aplicações práticas, construindo uma base sólida para a criação de interfaces funcionais, acessíveis e visualmente consistentes.

### 🎯 Objetivos do projeto

- Desenvolver habilidades na construção de interfaces web modernas.
- Praticar HTML5 semântico e boas práticas de acessibilidade.
- Dominar layouts com Flexbox e CSS Grid.
- Aplicar princípios de responsividade para diferentes tamanhos de tela.
- Explorar tipografia, cores, espaçamentos e hierarquia visual.
- Desenvolver interações com JavaScript Vanilla.
- Trabalhar com formulários, validações e feedback visual.
- Consumir APIs externas utilizando a Fetch API.
- Experimentar animações, transições e efeitos visuais.
- Construir um portfólio de projetos práticos para acompanhar a evolução no Front-End.

## 🧠 Conceitos praticados

Ao longo dos projetos, o laboratório aborda conceitos importantes para a construção de interfaces web.

**HTML e acessibilidade**

- HTML5 semântico.
- Organização hierárquica de títulos e conteúdo.
- Formulários e elementos de entrada.
- Estruturação de páginas com boas práticas de acessibilidade.

**CSS e design de interfaces**

- Flexbox e CSS Grid.
- Variáveis CSS e reutilização de estilos.
- Design responsivo e media queries.
- Tipografia, cores, espaçamentos e hierarquia visual.
- Animações e transições.
- Temas visuais e personalização de componentes.
- Organização e separação dos arquivos de estilo.

**JavaScript e interatividade**

- Seleção e manipulação de elementos do DOM.
- Eventos e interações do usuário.
- Validação de formulários.
- Atualização dinâmica do conteúdo.
- Consumo de APIs com Fetch API.
- Tratamento de respostas e erros.
- Feedback visual para ações do usuário.

**UI/UX e experiência do usuário**

- Consistência visual entre componentes.
- Organização e legibilidade do conteúdo.
- Hierarquia das informações.
- Clareza nas interações e nos estados da interface.
- Adaptação a diferentes dispositivos e resoluções.
- Usabilidade e previsibilidade dos elementos interativos.

## 🛠️ Tecnologias

As seguintes tecnologias são utilizadas no desenvolvimento dos projetos.

### Front-End

- **HTML5** — Estruturação semântica e organização do conteúdo.
- **CSS3** — Estilização, layouts, animações e design responsivo.
- **JavaScript ES6+** — Lógica, manipulação do DOM e interatividade.

- **Live Server** — Execução local das páginas durante o desenvolvimento.
- **Git** — Controle de versão.
- **GitHub** — Hospedagem do código e acompanhamento da evolução do projeto.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Dferreiraz/Interface.Lab.git
```

### 2. Entre na pasta do projeto

```bash
cd Interface.Lab
```

### 3. Abra o projeto no Visual Studio Code

```bash
code .
```

### 4. Execute no navegador

Abra o arquivo `index.html` localizado na raiz do projeto para acessar o menu principal.

Você também pode utilizar a extensão **Live Server** no VS Code para executar a página localmente e facilitar os testes durante o desenvolvimento.

Para acessar um projeto específico, abra o arquivo `index.html` correspondente à sua pasta.

> **Observação:** projetos que utilizam APIs externas podem depender de uma conexão com a internet. A utilização do Live Server também é recomendada para evitar limitações relacionadas à execução direta de arquivos locais no navegador.
