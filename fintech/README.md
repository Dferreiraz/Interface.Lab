## 💻 Sobre o projeto

O **Fintech** é um projeto de landing page institucional para uma empresa fictícia de tecnologia financeira, desenvolvido durante o curso Desenvolvedor Front-End no SENAI suiço-brasileira com foco em design corporativo, comunicação visual e apresentação de serviços relacionados ao controle financeiro.

A interface apresenta uma estrutura organizada, com navegação fixa, seção principal de destaque, áreas dedicadas aos diferenciais da empresa e um rodapé completo.

Sua identidade visual combina tons de roxo e azul escuro com tipografia profissional, buscando transmitir confiança, inovação e credibilidade — características importantes para interfaces do setor financeiro.

Desenvolvido com HTML5 e CSS3, o projeto tem como objetivo praticar a construção de páginas institucionais, a organização de conteúdo e a criação de layouts responsivos sem depender de frameworks de estilização.

### 🎯 Objetivos do projeto

- Construir uma landing page institucional com estrutura semântica.
- Desenvolver uma interface corporativa moderna e consistente.
- Praticar alinhamento e distribuição de elementos com CSS Flexbox.
- Aplicar hierarquia tipográfica para melhorar a leitura do conteúdo.
- Criar layouts adaptáveis para desktops, tablets e dispositivos móveis.
- Utilizar variáveis CSS para organizar cores, tipografia e espaçamentos.
- Trabalhar a hierarquia visual de títulos, textos e chamadas para ação.
- Aplicar princípios de UI/UX na apresentação de serviços financeiros.

## 🚀 Funcionalidades

A página reúne diferentes seções para apresentar a proposta de valor e os serviços da empresa.

| Funcionalidade | Descrição |
|---|---|
| **Header fixo** | Barra de navegação com logotipo, menu e botão de chamada para ação. |
| **Hero Section** | Apresentação principal com título, descrição e botão de ação. |
| **Seção de controle financeiro** | Área dedicada à apresentação de recursos e benefícios relacionados à gestão financeira. |
| **Seção de crescimento** | Conteúdo institucional com imagem e texto para destacar outros diferenciais. |
| **Seções de features** | Blocos alternados de imagem e texto para organizar a comunicação visual. |
| **Footer completo** | Rodapé com links de navegação, ajuda, redes sociais e formulário de newsletter. |
| **Design responsivo** | Adaptação da interface para diferentes resoluções de tela. |
| **Identidade corporativa** | Uso de cores, tipografia e espaçamentos consistentes em toda a página. |

> O projeto é voltado à apresentação institucional e à interface visual. Funcionalidades financeiras reais, como integração bancária, autenticação, movimentações e controle de transações, não são presumidas como implementadas.

## 🎨 Design System

O design system do Fintech foi pensado para manter uma identidade visual consistente, profissional e adequada ao segmento de tecnologia financeira.

### 🎨 Paleta de cores

| Cor | Código | Aplicação |
|---|---|---|
| Roxo primário | `#9130F4` | Destaques, botões e elementos de identidade visual. |
| Azul escuro | `#121139` | Fundos, títulos e elementos institucionais. |

### 🔤 Tipografia

- **Inter** — Família tipográfica utilizada para títulos, parágrafos, navegação e demais elementos textuais.

A hierarquia tipográfica utiliza diferentes tamanhos e pesos para distinguir títulos principais, subtítulos, textos descritivos e chamadas para ação.

### 📏 Sistema de espaçamento

O projeto utiliza um sistema de espaçamento baseado em múltiplos de 8 px, facilitando a consistência entre componentes e seções.

Exemplos de valores para essa escala:

- `8px` — Espaçamentos pequenos.
- `16px` — Distância entre elementos próximos.
- `24px` — Separação entre componentes.
- `32px` — Espaçamentos entre blocos.
- `48px` e `64px` — Separação entre áreas maiores da interface.

Esses valores representam a escala de referência do design system; os valores efetivamente utilizados devem corresponder aos definidos nos arquivos CSS.

## 🚀 Como executar o projeto

### 1. Acesse a pasta do projeto

Se você já clonou o repositório Interface.Lab, execute:

```bash
cd fintech
```

Caso ainda não tenha clonado o repositório, execute:

```bash
git clone https://github.com/Dferreiraz/Interface.Lab.git
cd Interface.Lab/fintech
```

### 2. Abra a aplicação

Abra a pasta no Visual Studio Code e execute o arquivo `index.html` utilizando a extensão **Live Server**.

Também é possível abrir o arquivo diretamente no navegador.

### 3. Explore as seções

Navegue pela página e observe a organização dos seguintes elementos:

1. **Header:** logotipo, menu de navegação e chamada para ação.
2. **Hero:** mensagem principal e apresentação da proposta de valor.
3. **Controle financeiro:** seção dedicada aos serviços e benefícios.
4. **Crescimento:** apresentação de diferenciais com texto e imagem.
5. **Footer:** links institucionais, redes sociais e newsletter.

Teste também a navegação em diferentes tamanhos de tela para observar o comportamento responsivo.
