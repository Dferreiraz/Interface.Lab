## 💻 Sobre o projeto

A **Loja do Celular** é um projeto de interface web inspirado em um e-commerce de smartphones, desenvolvido com foco em design moderno, identidade visual marcante e experiência do usuário.

A interface utiliza uma estética dark mode com cores vibrantes, combinando tons de preto, amarelo, lime e branco para destacar produtos, promoções e chamadas para ação.

O projeto apresenta seções de destaque, marcas de smartphones, ofertas especiais e diferenciais da loja, além de recursos interativos como cursor customizado, animações de entrada durante a rolagem e efeitos de hover.

Desenvolvido com HTML5, CSS3 e JavaScript Vanilla, o projeto permite praticar a construção de interfaces comerciais e explorar recursos visuais que tornam a navegação mais dinâmica.

### 🎯 Objetivos do projeto

- Desenvolver uma interface de e-commerce visualmente consistente.
- Praticar a criação de layouts com CSS Grid e Flexbox.
- Construir componentes visuais para produtos e promoções.
- Implementar animações utilizando CSS e JavaScript.
- Trabalhar com a Intersection Observer API.
- Criar interações personalizadas com eventos de mouse.
- Desenvolver uma interface responsiva para diferentes dispositivos.
- Aplicar princípios de hierarquia visual, contraste e experiência do usuário.

## 🚀 Funcionalidades

A interface reúne diferentes seções e efeitos para apresentar os produtos de forma moderna e envolvente.

| Funcionalidade | Descrição |
|---|---|
| **Hero Section** | Seção inicial com layout dividido entre texto e imagem de smartphone em destaque. |
| **Marcas e produtos** | Grid de cards com smartphones de marcas como Apple, Samsung e Xiaomi. |
| **Badges e preços** | Elementos visuais para destacar informações e ofertas dos produtos. |
| **Seção de promoções** | Cards com fundos amarelo e lime para chamar a atenção para ofertas especiais. |
| **Cursor customizado** | Cursor amarelo com anel visual que acompanha o movimento do mouse em dispositivos compatíveis. |
| **Scroll Reveal** | Animações de entrada dos elementos conforme o usuário percorre a página. |
| **Seção de diferenciais** | Grid com quatro colunas para apresentar os benefícios da loja. |
| **CTA para WhatsApp** | Chamada para ação direcionada ao contato pelo WhatsApp. |
| **Efeitos de hover** | Transições e respostas visuais ao interagir com elementos da interface. |
| **Design responsivo** | Adaptação do layout para dispositivos móveis, tablets e desktops. |

> O projeto é focado na interface e na interatividade visual. Funcionalidades como carrinho de compras, checkout, pagamentos e gerenciamento de pedidos não são presumidas como implementadas.

## 🎨 Design System

A identidade visual foi construída para transmitir uma estética tecnológica, moderna e expressiva, utilizando contrastes fortes e tipografia condensada.

### 🎨 Paleta de cores

| Cor | Código | Aplicação |
|---|---|---|
| Preto principal | `#080808` | Fundo principal da interface. |
| Preto secundário | `#111111` | Seções e superfícies escuras. |
| Preto elevado | `#1A1A1A` | Cards e elementos de contraste. |
| Amarelo | `#F5D800` | Destaques, cursor e chamadas para ação. |
| Amarelo claro | `#FFE033` | Variações de destaque e promoções. |
| Lime | `#C8F000` | Cards promocionais e elementos de ênfase. |
| Branco | `#FFFFFF` | Textos principais e elementos de alto contraste. |

### 🔤 Tipografia

O projeto utiliza uma combinação de fontes com características distintas para criar hierarquia visual.

- **Bebas Neue** — Títulos de destaque e elementos de display.
- **Barlow Condensed** — Labels, subtítulos e textos curtos.
- **Barlow** — Textos de conteúdo e informações gerais.

### ✨ Efeitos especiais

- **Custom Cursor:** cursor personalizado com destaque amarelo e efeito de anel.
- **Mix Blend Mode:** recurso de composição visual para integrar o cursor ao conteúdo.
- **Noise Overlay:** textura visual aplicada ao fundo para adicionar profundidade.
- **Float Animation:** animações de flutuação para elementos selecionados.
- **Fade Up:** animações de entrada com movimento vertical e mudança de opacidade.
- **Hover Effects:** transições aplicadas aos elementos interativos.

## 🚀 Como executar o projeto

### 1. Acesse a pasta do projeto

Se você já clonou o repositório Interface.Lab, execute:

```bash
cd loja-do-celular
```

Caso ainda não tenha clonado o repositório, execute:

```bash
git clone https://github.com/Dferreiraz/Interface.Lab.git
cd Interface.Lab/loja-do-celular
```

### 2. Abra o projeto

Abra a pasta no Visual Studio Code e execute o arquivo `index.html` com a extensão **Live Server**.

Também é possível abrir o arquivo diretamente no navegador.

### 3. Explore a interface

Navegue pelas principais seções da página:

1. **Hero:** apresentação inicial e smartphone em destaque.
2. **Marcas:** cards com produtos de diferentes fabricantes.
3. **Promoções:** áreas visuais dedicadas às ofertas.
4. **Features:** apresentação dos diferenciais da loja.
5. **CTA:** chamada para contato via WhatsApp.

Experimente também os efeitos de hover, o cursor personalizado e as animações ativadas durante a rolagem.
